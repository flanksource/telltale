# http_top

import { KindReference } from '../_components/KindReference';

Samples active incoming and outgoing HTTP exchanges in an attached JVM or an instrumented Go process. Each snapshot records the operation identity, elapsed time, direction, method, route or URL, and available thread and trace correlation. HTTP bodies belong to the `http` capture; this view contains metadata only.

```bash
telltale run http_top --agent java/checkout --allow-mutation --direction both --poll 5s --top 50 --duration 1m
```

The JVM agent observes subsequent operations on existing servlet deployments and HTTP client instances. Spring MVC and WebFlux retain their route and handler metadata when available. An asynchronous request or streamed response remains active until its body completes, closes, fails, or is cancelled. Operations whose starts were not observed at attachment are outside the capture boundary.

The Go SDK samples subsequent requests through `telltale.Handler` and `telltale.Transport` while the probe is armed. Start the capture and look for **Active HTTP requests** in the run’s Top view.

```sh
telltale run http_top --agent AGENT_ID --direction both --poll 1s --duration 30s
```

Profiles carry the snapshots using producer timestamps and sequence numbers. An empty complete snapshot clears the view; missing snapshots leave the previous reading stale. Elapsed values are ages at a point in time and must not be summed across snapshots. Top limits and dropped observations are reported separately.

Definitions use the JVM instrumentation section:

```yaml
apiVersion: telltale.flanksource.com/v1alpha1
kind: TraceDefinition
metadata: {name: service-http}
spec:
  instrument:
    jvm:
      httpTop:
        - agent: {selector: {service.name: checkout}, wait: true}
          direction: both
          poll: 5s
          top: 50
```

JVM attachment and arming require mutation permission. Inspect the connected JVM's capabilities for its supported libraries and versions.
