# Tracing parity

This audit compares the Telltale capture and Java agent implementations with the changes after `c9e0ce0099` in oipa-cli's `internal/trace/{kinds,profiler,notificationcapture,probefollow}` and `plugins/oipa-diag`. It also covers the existing behavior the migration depends on. A port uses Telltale's existing target, frame and storage contracts.

| Behavior | Status | Source and Telltale evidence |
| --- | --- | --- |

| A host resolves a saved query profile and prepares its read | present | oipa-cli `kinds/query_profile.go`; `pkg/tracing/query/reader.go:75` and `pkg/tracing/query/query_spec_test.go:122`. |
