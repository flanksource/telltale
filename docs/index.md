# Telltale

Telltale records traces and process activity for commands, running processes, and hosts. Explore captures from the terminal or the web workspace, receive OpenTelemetry traces, and monitor resource usage across process groups.

[Get started](/getting-started)

## Explore the guides

- [Web workspace](/web-ui): start captures, inspect records, manage connections, and explore traces.
- [OpenTelemetry receiver](/otlp-receiver): receive traces over OTLP and inspect them in Telltale.
- [Resource monitoring rules](/rules): preview CEL-based rules and configure hooks for process groups.
- [SQL Server and JVM captures](/sqlserver-jvm): collect SQL Server events and JVM profiles.
- [Trace kinds](/traces/): choose a capture and see its target, options, and examples.

For the full command and configuration reference, see the [repository README](https://github.com/flanksource/telltale#readme). The CLI also provides `telltale --help` and help for each subcommand.
